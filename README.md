# DODGE READ - 消えたボール

ドッジボールの軌道予測を鍛える、動画撮影不要・完全自主練型の試作Webアプリです。

## 現在の仕様

- 1セット15球
- ボールは画面奥から手前へ移動し、途中で消える
- 到達位置を「左・中央・右」から回答
- 回答後、消えた後の軌道を再生
- 直近5球の正解数によりレベル1〜10を自動調整
- 正解数、反応時間、左右別正解率、最高レベルを表示
- ベストスコアとプレイ回数を端末内に保存
- ログイン、個人名、チーム管理、撮影素材は不使用
- PWA用のオフラインキャッシュを同梱

## ローカルで確認

```bash
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開きます。

> `index.html` を直接開くより、ローカルサーバー経由の方がService Workerを含め正しく動作します。

## テスト

```bash
npm test
```

依存パッケージはありません。Node.js標準のテスト機能を使います。

## GitHub Pages

`.github/workflows/pages.yml` を同梱しています。GitHubリポジトリへPush後、Settings → PagesでGitHub Actionsを選ぶと公開できます。
